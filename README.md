
# 🧮 Complete Linear Algebra Course with Python
[![YouTube](https://img.shields.io/badge/YouTube-Watch%20the%20Course-red?style=for-the-badge&logo=youtube)](https://www.youtube.com/@z.integratemaths)

Welcome to the **Complete Linear Algebra with Python** repository! 

This project is designed for BS students, computer science majors or others, and self-learners who want to bridge the gap between abstract mathematical theory and practical programming. Instead of just reading textbook formulas, you will learn how to implement, visualize, and solve Linear Algebra problems using **Python, NumPy, and Matplotlib**.

---

## 🎯 What's Inside?
This repository is organized **chapter-wise and topic-wise** for easy navigation. Every folder contains:
*   **Python Scripts (`.py`)**: Step-by-step implementations of core concepts (no skipped steps!).
*   **Visualizations**: 2D and 3D graphs generated to make abstract concepts (like subspaces and transformations) crystal clear.
*   **Practice Exercises**: Python solutions to standard textbook problems.

---

## 📂 Repository Structure (Course Syllabus)

*   📁 **`01-Linear-Equations-and-Matrices`**
    *   `gaussian_elimination.py` — Solving systems of linear equations step-by-step.
    *   `matrix_operations.py` — Addition, multiplication, and inverses.
*   📁 **`02-Determinants`**
    *   `determinant_calculator.py` — Finding determinants of nxn matrices.
    *   `geometric_meaning.py` — Visualizing how determinants scale area and volume.
*   📁 **`03-Vectors-in-Rn`**
    *   `vector_operations.py` — Dot products, cross products, and norms.
    *   `vector_visualizer.py` — Plotting vectors in 2D and 3D space.
*   📁 **`04-Vector-Spaces-and-Subspaces`** *(Current Focus)*
    *   `axioms_checker.py` — Verifying the 10 axioms of a vector space.
    *   `subspace_closure.py` — Testing closure under addition and scalar multiplication.
    *   `function_space.py` — Visualizing pointwise addition of functions.
*   📁 **`05-Linear-Transformations`**
    *   `transformation_matrix.py` — Building transformation matrices.
    *   `animate_rotation.py` — Animating 2D rotations and reflections.
*   📁 **`06-Eigenvalues-and-Eigenvectors`**
    *   `eigen_calculator.py` — Finding eigenvalues and eigenvectors using NumPy.
    *   `eigen_visualizer.py` — Visualizing how eigenvectors remain on their span during transformation.
*   📁 **`07-Inner-Product-Spaces`** *(Coming Soon)*
*   📁 **`08-Numerical-Linear-Algebra`** *(Coming Soon)*
